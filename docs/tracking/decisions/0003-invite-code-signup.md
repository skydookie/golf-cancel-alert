# 0003 — 공개 가입이 아니라 초대코드 게이트

**맥락**: 앱 자체 로그인을 이메일+비밀번호로 만들기로 하면서, 회원가입을 URL만 알면 누구나
할 수 있게 열어둘지, 지인만 들어오게 막을지 결정이 필요했다. 무료 티어 클라우드(DB·호스팅·
스캔 스케줄)로 운영하기로 이미 정해진 상태였다.

**결정**: 유효한 초대코드 없이는 가입할 수 없다(`INVITE_CODE` 환경변수와 정확히 일치하는
값을 제출해야 계정이 생성됨).

**대안과 기각 사유**: 누구나 가입 가능한 방식은 구현이 가장 간단하지만, 낯선 사람이 가입하면
무료 티어 자원(특히 몇 분마다 도는 스캔 스케줄)을 나눠 쓰게 되어 의도한 "본인+소수 지인"
규모를 벗어난다는 이유로 기각. 운영자가 계정을 직접 만들어주는 승인제는 매번 수동 개입이
필요해 초대코드보다 번거롭다는 이유로 기각.

**결과**: 초대코드는 현재 앱 전체에 공용 값 하나뿐이다 — 누가 가입했는지 코드 단위로
추적하지 않는다. 코드가 유출되면 그 코드를 아는 모든 사람이 가입할 수 있으므로, 코드
유출 시 `INVITE_CODE` 값을 교체해야 한다(개별 1회용 코드 관리 기능은 구현되지 않음 —
`docs/tracking/status.md` "남은 범위" 참고).
